# Dataset Card — Experiment C Sentiment v2 (480, 160/label)

Scaled Arabic–English code-switched **sentiment** training data for Multi-Agent BERT Experiment C,
generated by the (frozen) Modified_Version SwitchLingua pipeline (`gpt-4o-mini`), accumulated over
multiple windows, filtered, de-duplicated, and balanced. **NER untouched; no prompt/core/pipeline change.**
Supersedes the 240 set (which is preserved, not overwritten).

- Build: `manage_sentiment_data.py merge --target-per-label 160 --out-name switchlingua_sentiment_train_480_160perlabel`.

## Limitations
- **Mixed generation configs (heterogeneous cs_ratio).** 104/480 target 70% Arabic (legacy pilot_v1);
  376/480 target 50–60% (v3). Acceptable for sentiment (label is cs_ratio-independent), but not a
  single-config corpus.
- **Generator-labeled, LLM-judged** (target label + TaskValidator, gpt-4o-mini); no human verification yet.
- **Neutral** remains the hardest class; can lean mildly aspirational (frozen-prompt limit — see CS_VALIDITY_DIAGNOSIS.md).
- **Topic imbalance:** health under-represented (33).
- Single model / single language pair (gpt-4o-mini, Arabic-matrix + English).

## Status
**NOT yet trained.** 2× the size of the 240 set (which scored 0.590 acc / 0.562 macro-F1 on EESA test).
Intended next step: retrain xlm-roberta-base on this 480 set and re-evaluate on EESA test vs the 240 model
(controlled: same Adafactor setup). EESA test remains the held-out anchor.
